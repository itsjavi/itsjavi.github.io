I wanted a simpler note-taking app: plain Markdown files, several separate vaults, and every change versioned with git
without having to think about it.

- **Notes are files.** Any folder can be a vault. No database and no proprietary format.
- **Versioned automatically.** Edits are committed a few seconds after you stop typing. Version History compares and
  restores any version.
- **Templates for reusable prompts.** Add parameters to a note, fill in a form, copy the result.
- **Voice notes.** Record into a note and transcribe it on device. The audio never leaves your Mac.
- **Incognito notes** that are never committed, and attachments stored with Git LFS.
