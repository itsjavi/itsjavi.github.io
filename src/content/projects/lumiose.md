A web framework for everything from static sites and SPAs to full-stack apps: TSX with scoped CSS built in, signals,
and 0 kB of JavaScript until a page needs it.

Try it in the [playground](https://itsjavi.com/lumiose/playground) or start with the
[getting started guide](https://itsjavi.com/lumiose/docs/getting-started).
